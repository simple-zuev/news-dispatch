# Public Reader Deployment

The public GitHub Pages site is generated by GitHub Actions. On push to `main`,
the Pages workflow renders the reader into `site/`, validates the generated
output, uploads `site/` as the Pages artifact, and deploys that artifact.

Do not commit generated `site/` artifacts for reader UI changes. Change the
source-controlled renderer, CSS, tests or docs that own the behavior, then let
the Pages workflow rebuild the published site from the current pipeline.

The deploy build uses:

```bash
python3 tools/build_site.py --ranking-mode live --media-mode skip
```

Keep `--media-mode skip` for Pages until the media resolver is stable enough for
unattended deploys. This avoids making publication depend on remote media
lookups.

After a deploy, check the published reader:

```text
https://simple-zuev.github.io/news-dispatch/
```
